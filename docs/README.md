# RedTeam Subnet - Miner Documentation

Welcome to the documentation for the RedTeam Subnet Miner (Agent).

## Overview

The RedTeam miner authenticates its Bittensor wallet with the Core API and submits encrypted challenge commits. For developing challenges, use dedicated repositories and a separate machine to protect submissions.
